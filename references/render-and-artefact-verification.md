# Render and artefact verification

A deliverable is not finished when the file is written. It is finished when the file has been
re-opened and checked against the source document. Rendering silently drops, truncates and
reflows, and a QA report that misstates its own finding counts is worse than no report.

## The check list, every reissue

1. **Page count** — `pypdf.PdfReader(path)` → `len(reader.pages)`. A drop of several pages means a
   table or a section overflowed and was clipped.
2. **Stale strings** — after any edit to the findings, extract the text and grep for the values you
   removed: superseded severity counts (`3 Critical`), withdrawn identifiers (an old FRN, a
   superseded APR, an old monthly figure), and old owner labels (`Us — DSC`, `the platform owner — build`).
3. **New strings present** — grep for each sentence you claim you added. "I updated H3" is a claim
   until the PDF contains it.
4. **Masking artefacts** — a naive secret filter turns real numbers into `***`. Check the phone
   number, prices and postcodes survived; use substring checks on the known values rather than a
   regex that eats digits.
5. **Table integrity** — a findings table that reflows across a page break often loses its header
   row. Check the PDF visually, not just the text layer.
6. **The DOCX is a second artefact** — it is generated by different code and can fail independently.
   Extract its paragraphs too; do not assume the PDF check covers it.

## Rendering route that works on this machine

Markdown → styled HTML → headless Chrome:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="$OUT.pdf" "file://$HTML"
```

Then `python-docx` for the DOCX from the same intermediate structure, so the two cannot disagree
about content. Chrome ignores `@page` margin boxes in some versions — put the footer as CSS
`position: fixed` inside the body, or omit page numbers rather than discover they are missing.

## Delivery check

Stage deliverables in `~/.hermes/profiles/dsc/cache/documents/` and emit a bare `MEDIA:/abs/path`
on its own line. Files left in `~/Documents` never deliver. Confirm the file exists on disk at the
staged path before claiming it — the user opens every file, so a broken link is immediately visible.
